# 从一个模糊的研究方向开始

最近开始正式接触自己之后可能长期研究的方向。

老师给我的建议大致是：

> 关注强化学习的最新算法，用作智能体建模优化协同调度，场景可以考虑电力—交通—通信网，重点关注电动汽车、电动重卡、无人机等资源……

这并不是一个已经确定好的“小课题”，而更像是一个长期研究方向。

所以我现在并没有一个明确的论文题目，甚至还不知道最后真正值得研究的问题是什么。

## 我现在知道什么？

目前我大概知道几个课题中的关键词：

- 强化学习
- 智能体
- 协同调度
- 电力系统
- 交通系统
- 通信系统
- 电动汽车
- 电动重卡
- 无人机
- V2G
- 配电网韧性
- 极端灾害
- 灾后恢复

但“知道这些关键词”和“理解这个研究方向”显然是两回事。

## 我现在不明白什么？

具体怎么入手这样一个宏大的问题？

具体要不要拆分不同场景，然后通过某种方法对这些场景进行统一？

正常运行和极端灾害情况下的资源调度，是不是也应该采用类似的逻辑？

这些 Agent 具体是什么？它们又应该在什么情况下发挥什么样的作用？

如果讨论的是韧性相关的问题，那么它显然不仅仅是成本与个体意愿之间的简单优化问题。比如，是否不能只把 EV 看作移动电源，或者仅仅看作通信网络中的一个接收方？

V2G 的技术涉及双向充电桩，这一技术目前仍然属于较新的应用方向。那么未来是否会陆续出现更多新的设备和技术，使得电力—交通—通信网络中的主体不再局限于目前这些电气设备？

如果这种变化确实可能发生，那么未来在哪些方向进行设备和技术革新可能更有价值？

这些问题目前我都没有答案。

## 因此，我准备先从文献开始

我现在不准备直接确定研究题目。

第一步是去阅读相关领域的论文，看看其他研究者到底是如何定义这些问题的。

我准备首先考虑如何获取论文，以及不同论文能够提供什么层级的信息和知识。

我初步把论文分为以下层级：

| 层级 | 介绍                             |
| ---- | -------------------------------- |
| L1   | 介绍某个电气设备或元件的论文     |
| L2   | 介绍 EV 与 V2G 技术的论文        |
| L3   | 有关 V2G 与配电网关系的论文      |
| L4   | 有关移动储能资源的论文           |
| L5   | 有关电力—交通—通信网络的论文   |
| L6   | 有关电网与灾害恢复的论文         |
| L7   | 有关多智能体电网优化的论文       |
| L8   | 有关跨场景电网韧性与自适应的论文 |
| L9   | 有关机器学习优化电网的论文       |

这里的层级并不意味着论文的重要程度，而是我目前按照自己理解的知识关联程度，对后续需要阅读的内容进行的一个初步分类。

随着阅读的深入，这个分类可能会不断调整。

## 这一阶段的目标

不是马上找到一个可以发表的课题。

而是逐渐回答：

> **怎么去拆解这个大的研究方向？**

以及：

> **别人已经研究到了哪里？**

最后再看看：

> **还有什么问题没有被很好地解决？**

这应该才是我现在真正需要做的事情。
