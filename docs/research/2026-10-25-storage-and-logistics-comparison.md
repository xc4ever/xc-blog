# 固定储能与发车调整对照

日期：2026-10-25。以下为已实际求解的合成算例，不是真实园区或市场实验。

## 1. 目的与共同条件

检查上一轮90分钟返场延误造成的500→200 kW下降，能否由固定储能或简单运输调整解决。

共用基准：10辆车、相同任务能耗、5个假设双向接口、服务时间14:00—16:00、全站净输出上限500 kW。车辆期末SOC至少等于初始80%。延误与任务在规划前完全已知，没有真实车型双向能力保证。

## 2. 固定储能对照

容量和功率为假设。储能以独立变流器接入同一节点，不占车辆接口；充放电效率各95%，SOC为20%—90%，初始80%，期末至少80%。允许服务前充电、服务后恢复，站点净进口仍不超过原600 kW余量。未安排储能其他用途。

| 储能容量 | 储能功率 | 与延误车队共同提供的持续净输出 |
| --- | --- | --- |
| 无 | 无 | 200 kW |
| 200 kWh | 300 kW | 433 kW |
| 500 kWh | 100 kW | 300 kW |
| 500 kWh | 300 kW | 500 kW |
| 2000 kWh | 100 kW | 300 kW |
| 2000 kWh | 300 kW | 500 kW |

结果体现功率与能量的区别：2 MWh不保证300或500 kW输出，还需变流器功率。200 kWh情形允许提前充至90%，不能只按初始SOC估计服务期可用电量。

进一步禁止车辆反向放电，仅保留运输与正常补能：

| 固定储能 | 车辆反向放电 | 持续净输出 |
| --- | --- | --- |
| 2 MWh / 300 kW | 禁止 | 300 kW |
| 2 MWh / 500 kW | 禁止 | 500 kW |

**解释**：本例若已有足够功率且无其他任务的固定储能，500 kW请求不需要调用重卡反向供电。它不证明V2G没有价值，但说明单节点请求尚不足以证明移动电池的额外价值。

赤峰参考项目公开了2 MWh储能，因此后续不应省略该资源。项目实际储能功率、SOC与用途未知，本表不是项目能力评估。

## 3. 有限发车调整

只允许每辆车第二趟在原始时刻前后有限移动，其他两趟不变。第二趟行驶时间、54 kWh行驶耗电和90分钟额外返回延误不变；每项任务均完成，没有取消任务或跨车重分配。

这是假设客户与装卸资源允许的日前可行域，不是已证实的时间窗。延误在发车前已知，不能将提前发车称为突发延误发生后的补救。

先最大化持续供电，再在保留最大输出时最小化总绝对发车偏移：

| 每车允许幅度 | 持续净输出 | 达到该上限的最小总绝对偏移 |
| --- | --- | --- |
| 不允许 | 200 kW | 0分钟 |
| 前后30分钟 | 400 kW | 60车·分钟 |
| 前后60分钟 | 500 kW | 120车·分钟 |
| 前后90分钟 | 500 kW | 120车·分钟 |

前后60分钟情形的一组安排：第2、7辆车各提前30分钟，第8辆车提前60分钟，其余不变。120车·分钟是三辆车偏移总和，不是运输延误或经济成本。

尚未计算额外人工、装卸冲突、客户接受度和生产节拍，因此不能说免费恢复或经济最优。当前候选窗口不与另外两趟重叠；扩展参数范围时须补一般任务不重叠和司机约束。

## 5. 场景判断

本例验证任务时序会改变电力能力，但常规资源与提前调度均可解决。它适合作为模型自检，暂不足以支撑有明确创新性的课题。

下一轮场景调查优先回答：

1. **供电需求在哪个节点？** 同一场站优先比较固定储能；多个不能直接共享电源的节点才可能体现移动价值，且必须有工程证据。
2. **信息何时到来？** 真实突发任务需要冻结已执行动作，不能提前知道未来再声称在线恢复。
3. **运输可以怎么改？** 若生产或客户不允许提前，本轮移峰方案失效；若允许，需要把调整代价与其他资源比较。
4. **固定储能还有哪些任务？** 既有削峰与备用需求都要计入，不能任意假定储能永远空闲或永远不可用。

生产与建设并存仍保留，但须补分区供电接口、临电建设阶段、运输路线与任务兼容性证据。不能为了使重卡胜出而任意切断电力连接或排除固定备用方案。

## 6. 下一步

调查园区分区供电、临时供电与移动应急电源的真实应用，核查固定电源覆盖困难的具体节点，以及货运任务是否自然到达这些节点。若证据不足，转向补能保障与物流协调也成立。

本轮无理由进入RL训练；应先明确实际场景、可观察信息和常规资源的完整比较。
