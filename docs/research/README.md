# 工业园区电动重卡研究记录

本目录为内部研究工作资料，不自动成为博客文章。研究对象为10辆重卡的初始规模；未取得导师实际车队的任务、车型与运行数据。

与导师交流时优先阅读：[阶段讨论简报](2026-10-25-advisor-discussion-brief.md)，包含场景选择、文献边界、已做实验与待核实问题。

## 当前结论（2026-10-25）

已完成场景案例调研、相近论文对照、国内车型参数登记，以及第一个可运行的合成供电能力模型。固定任务延误会降低供电能力，但固定储能与提前发车能在所设条件下补足缺口；还不能认定重卡反向供电必要或存在创新点。

当前以“既有园区10辆重卡的生产短驳与补能”为工作主场景，建设扩建作为待核实的任务变化来源。分区检修临时供电保留为扩展调查；尚无同一园区完整证据。下一步先取得能复盘一天的任务、SOC、补能与场站记录。
